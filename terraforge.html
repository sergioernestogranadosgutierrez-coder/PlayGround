▶️ Cómo unirse

Java (PC)

  1. Abre Minecraft Java (versión 1.21).
  2. Multijugador → Añadir servidor.
  3. Pega TerraForge.Aquatis.io y guarda.
  4. Doble clic para entrar.

Bedrock (móvil/consola)

  1. Abre Minecraft → Jugar → Servidores → Añadir.
  2. Dirección: TerraForge.Aquatis.io, puerto 25593.
  3. Guarda y únete.
