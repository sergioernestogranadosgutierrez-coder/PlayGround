Tutorial: Tu PC (5 min)
  1. Descarga el servidor oficial (ver guía del juego).
  2. Abre la carpeta y ejecuta el .jar / .exe / .x86_64.
  3. No abras puertos: instala Playit.gg y comparte el enlace con tus amigos.
Tutorial: Oracle Cloud Always Free
  1. Crea cuenta en oracle.com/cloud/free con tarjeta (solo verificación).
  2. Crea instancia Ampere A1: 4 OCPU, 24 GB RAM, Ubuntu 22.04.
  3. Abre puertos en el firewall: sudo iptables -I INPUT -p tcp --dport 25565 -j ACCEPT
  4. Instala Java / SteamCMD según el juego y lanza el servidor con tmux o systemd.
Tutorial: Google Cloud e2-micro
  1. Activa la capa gratuita en console.cloud.google.com.
  2. Crea VM e2-micro (us-central1), Ubuntu 22.04, 30 GB disco.
  3. Marca “Permitir tráfico HTTP/HTTPS” y añade regla de firewall para el puerto del juego.
  4. Sube los archivos por SSH y ejecuta el servidor.

🔌 Conexión sin abrir puertos

El router bloquea conexiones entrantes. Estas herramientas crean un túnel seguro sin tocar el router.

🚀 Playit.gg

Lo más fácil. Instalas, te da una dirección pública. Ideal para Minecraft, Terraria, Valheim.

  1. Regístrate en playit.gg
  2. Instala el programa y añade un túnel TCP/UDP al puerto de tu juego.
  3. Comparte la dirección xxx.playit.gg:port

🛡️ Tailscale

Red privada. Todos instalan Tailscale y juegan como si estuvieran en LAN. Ideal para Stardew Valley y juegos sin servidor dedicado.

  1. Instala Tailscale en tu PC y en la de cada amigo.
  2. Inicia sesión con la misma red (o comparte invitaciones).
  3. Conéctate a la IP Tailscale del anfitrión (100.x.y.z).

🌐 ZeroTier

Como Tailscale pero open-source. Bien para Valheim y Factorio con amigos técnicos.

  1. Crea red en my.zerotier.com, instala cliente en cada PC y únete con el ID de red.

🎮 Radmin VPN

El clásico estilo Hamachi. Solo Windows, muy simple para Terraria y Minecraft LAN.

  1. Instala Radmin VPN, crea red con nombre y contraseña, tus amigos se unen.
💡 ¿Cuál conviene? Minecraft/Terraria públicos → Playit.gg. Stardew/coop privado → Tailscale. Solo Windows y prisa → Radmin.
