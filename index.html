Sin claves la app funciona en modo demo (respuestas simuladas). Con claves llama directo a cada API desde tu navegador, sin servidor intermedio.

¿Dónde consigo las claves?
  • ChatGPT: platform.openai.com → API keys
  • Claude: console.anthropic.com → API keys
  • Gemini: aistudio.google.com → Get API key

Opciones

FusionAI no envía tus claves a ningún servidor propio. Todo va directo del navegador a OpenAI / Anthropic / Google.
